# 雅安雨城区买房决策看板

## GitHub Pages 发布

1. 将本目录中的 `index.html` 和 `.nojekyll` 上传到仓库根目录。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择包含文件的分支（通常是 `main`）和根目录 `/ (root)`，保存。
5. 发布后使用 GitHub Pages 提供的网址访问。

## 数据保存说明

网页中可编辑台账的数据保存在当前浏览器的 localStorage 中：

- 同一手机、同一浏览器、同一 GitHub Pages 域名下通常会保留；
- 不会自动同步到其他手机或电脑；
- 无痕模式、清除网站数据或更换域名后可能丢失；
- 建议定期使用网页内的“导出”按钮备份 CSV。
